# Ручная проверка ASH&LEAD

Чек-лист по сценариям из раздела 16 промпта. Проходить в редакторе/собранной
игре, отмечать результат и записывать найденные дефекты (что делали, что
ожидали, что получили).

## Запуск

1. Установить Godot 4.7 (https://godotengine.org/download).
2. `godot --path .` из папки проекта либо импортировать проект в редакторе и
   нажать «Запустить».
3. Графика: `forward_plus`, сглаживание отключено — ожидаемо «пиксельный» вид.

## Сценарии

### 1. Меню и тренировка
- [ ] Игра стартует без ошибок парсинга/импорта.
- [ ] Главное меню открывается, все кнопки реагируют.
- [ ] «Тренировка» запускает матч с ботами.
- [ ] Пустые слоты занимают боты.

### 2. Управление и бой
- [ ] Движение WASD, прицеливание мышью независимо от движения.
- [ ] Стрельба (ЛКМ), прицеливание (ПКМ), перезарядка (R), смена слотов (1/2/3).
- [ ] Взаимодействие (E) с дверями, медкомплектом, объектом миссии.
- [ ] Гаджет (F/4), ближний бой (V), присед (Ctrl), спринт (Shift).
- [ ] Спринт громче и ухудшает точность; присед снижает заметность.
- [ ] Боезапас, перезарядка и гаджет отображаются в HUD.

### 3. Боты и приказы
- [ ] В лобби боты заполняют недостающие места.
- [ ] Открыть колесо приказов (G) — 11 приказов, подсказки читаемы.
- [ ] Бот выполняет приказ (следовать/удерживать/перейти/прикрыть/помочь/тихо…).
- [ ] После смерти игрока доступны «Наблюдать» и «Управление ботом».

### 4. Карта
- [ ] Карта процедурная: одинаковый seed даёт одинаковую карту, разный — разную.
- [ ] Все цели, эвакуация и добыча достижимы; спавны не в стенах.
- [ ] Двери проходимы, открываются при приближении.
- [ ] В каждой из 6 тем есть комнаты, коридоры, укрытия, свет.

### 5. Гражданские
- [ ] Рутина, реакция на шум, подозрение, поиск, бегство, укрытие, паника.
- [ ] Паника передаётся соседям.
- [ ] Можно отдать команду гражданскому (меню гражданских).
- [ ] Убийство/ранение гражданских не даёт награды, повышает тревогу.

### 6. Режимы
- [ ] «Установка»: закладка/обезвреживание устройства, без возрождений.
- [ ] «Налёт»: добыча и эвакуация, полиция прибывает с задержкой.
- [ ] «Переговоры»: удержание заложника, меню переговоров влияет на исход.
- [ ] «Порог»: последовательный захват зон.
- [ ] «Чёрный архив»: захват объекта и доставка, объект перехватывается.
- [ ] Аркадные (TDM/FFA/гонка вооружений/захват точек): респауны, лимиты,
      после матча — итоги и повторы.

### 7. Полиция и время
- [ ] В режимах с задержкой полиция появляется после фазы/сигнала, а не мгновенно
      в поле зрения.
- [ ] Таймер раунда и фазы отображаются корректно.

### 8. Сеть
- [ ] «Создать лобби»: код комнаты, список игроков, готовность, чат.
- [ ] «Подключиться» по адресу `IP:порт`.
- [ ] Ограничение често показано: репликация матча не реализована, удалённые
      игроки — NPC.

### 9. Настройки
- [ ] Управление: переназначение клавиш сохраняется и работает.
- [ ] Звук: громкости, включение музыки/SFX, субтитры.
- [ ] Доступность: кровь, вспышки, тряска, индикатор шума, цветовые режимы,
      контраст — заметно меняют картинку/поведение.
- [ ] Камера: зум, запаздывание, следование.
- [ ] Интерфейс: масштаб, язык RU/EN переключаются и применяются.

### 10. Производительность
- [ ] ~60 FPS при обычной нагрузке (включить счётчик в настройках).
- [ ] Без зависаний при генерации карты и смене режима.

## Заметки

- Настройки хранятся в `user://` (папка пользователя Godot), профиль — там же.
- Локаль: русский по умолчанию, английский в настройках; 374 ключа.
- Автотест в CI покрывает только часть сценариев: парсинг, загрузку ресурсов,
  валидацию данных и «меню → матч с ботами».
